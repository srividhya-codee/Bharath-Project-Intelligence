# Bharath Project Intelligence

Bharath Project Intelligence is a web-based platform designed to help monitor and analyze government projects using Artificial Intelligence.

## Features

- Project monitoring and tracking
- AI-powered project analysis
- Government project information management
- RAG-based information retrieval
- LLM-powered question answering
- LangChain and LangGraph integration
- Simple and user-friendly interface

## Technologies Used

### Frontend
- React
- TypeScript
- Vite

### Backend
- Python
- FastAPI
- REST API

### AI / ML
- Large Language Models (LLM)
- Retrieval-Augmented Generation (RAG)
- LangChain
- LangGraph

### Other Tools
- Git
- GitHub
- Docker
